# 轻译

轻量 Windows 划词翻译与截图翻译工具，界面参考 Cherry Studio 的紧凑工具栏和翻译结果窗。

## 使用

运行 `发布版/轻译.exe` 打开设置。填写硅基流动 API Key，按需修改 API 地址与文字/图片模型，然后点“保存设置”。“测试连接”会按顺序向两个模型各发送一次短请求，可能产生用量，并分别显示耗时。翻译窗也会区分接口已连通、模型生成中、首段译文和总耗时。

- **划词翻译**：拖动选择文本，出现浮动工具栏后点“翻译”；工具栏可复制所选文字。
- **截图翻译**：按住 Shift 点击鼠标右键，在浅灰遮罩上用左键框选，点“图片翻译”。按 Esc 或右键取消。图片通过多模态接口直接发送，不使用本地 OCR。
- 主设置页提供工具栏实时预览和连续尺寸滑块，保存后同时应用于文字与图片工具栏。工具栏可从左侧“译”字手柄拖动；两类窗口可拖动和调整大小，并记住上次的位置与尺寸。
- 译文使用流式响应逐段显示；任务栏、托盘、窗口和 EXE 共用设置页的“译”字品牌图标。
- 结果窗口的“显示原文/显示原图”会记住最后一次选择，后续翻译窗口默认沿用该状态。
- 单击主窗口关闭/最小化会缩到托盘；托盘菜单可打开设置、暂停监听或退出。默认不开机自启。
- 开启“启动后缩到后台”后，第一次配置仍会显示窗口；保存 API Key 后下次启动可从托盘打开设置。传入 `--show` 可强制显示设置窗口。

默认接口为 `https://api.siliconflow.cn/v1`，文字和图片模型分别默认为 `Qwen/Qwen3.5-9B`。两个模型输入框下方有“启用模型思考”开关，默认关闭；该选择会保存，并同时应用于文字与图片请求。硅基流动仅在模型 ID 为 `Qwen/Qwen3.5-9B` 时收到 `enable_thinking` 参数。

## 安全与数据

API Key 在本机用 Windows DPAPI 按当前用户加密，保存在 `%APPDATA%\QingYi\settings.json`。源码和发布文件不包含用户密钥。选区和截图先在内存处理；只在用户点击翻译后向设置的 API 地址发送相应内容。程序日志不保存原文或译文。

## 构建

在项目目录运行 `powershell -ExecutionPolicy Bypass -File .\publish.ps1` 生成 Windows x64 单文件发布版。需要 .NET 8 Desktop Runtime 才能运行；当前开发机已具备该运行时。源码构建需要 .NET 8 SDK：

```powershell
dotnet restore .\轻译\轻译.csproj
dotnet publish .\轻译\轻译.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o .\发布版
```

项目附带 `.tools\dotnet` 的本地 SDK 只为当前构建使用，不属于最终发行包。

## 已知边界

- 截图取自各显示器的桌面图像；受 DRM 保护的视频、安全桌面、管理员窗口或特定远程桌面环境可能无法捕获。
- 划词先读 Windows UI Automation 文本选区，无法读取时才尝试 Ctrl+C，并仅在剪贴板仍是本次复制结果时恢复原剪贴板。个别应用不支持这两种方式。
- 一次最小文字请求在模型默认思考时约 4.31 秒收到首段；关闭思考后，HTTP 响应头与首段约 0.41 秒、总计约 0.47 秒，且没有思考字段。样本数少，耗时不代表稳定速度保证。
- `Qwen/Qwen3.5-9B` 的图片输入能力尚未做真实 API 请求验证；本地模拟已验证图片载荷和流式响应处理，不能代替账户权限和多模态端到端验收。
- 多屏与混合 DPI 已按每屏捕获、虚拟桌面坐标裁剪实现，但尚未在所有缩放组合和显示器拓扑逐一验证。

完整需求、界面草图和验收范围见 [项目说明书](./项目说明书.md)。
